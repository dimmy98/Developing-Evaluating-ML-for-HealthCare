    Dataset, reproducibility & interpretation

    Only four features are used: age, sex, BMI and smoking status. Children and region are not model inputs. Predictions are associations learned from this dataset. No uncertainty interval or clinical validity is claimed.

    Feature effects use one-at-a-time replacements. Importance uses repeated holdout permutations. Charts export aggregate counts, rather than original test records.
