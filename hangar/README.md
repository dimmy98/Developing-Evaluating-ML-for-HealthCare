# The Hangar

A separate interactive portfolio scene. Open `hangar/index.html` through GitHub Pages or an HTTP server.

- Pip roams over the visible page and hops onto visible card edges.
- Click Pip for a guide, or enable Follow Cursor.
- Click either aircraft to open its project cockpit.
- Healthcare instruments read the existing verified ML Lab experiment export.
- Brain-activity results are explicitly historical; the signal drawing is illustrative.
- Night Flight (or the N key) switches the lighting and starfield.
- Launch Demo Flight triggers a six-second illustrative flyby.
- Pause Pip stops autonomous movement and ambient CSS animations.
- System reduced-motion settings disable autonomous animation by default.
- No personal inputs, trackers, external libraries or accounts.

Original profile README, dashboard and ML Lab are separate and unchanged.
